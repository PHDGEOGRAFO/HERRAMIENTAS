Geocodificador Territorial de Santiago

SECPLAN · Subdirección de Planificación y Sustentabilidad · Oficina de Planificación Estratégica

1 · Direcciones

Una columna DIRECCION, o CALLE y NUMERO. Campo opcional COORD_GOOGLE solo para registros no localizados (latitud, longitud).

2 · Bases cartográficas preestablecidas

Comprobando callejero y coberturas territoriales…

Fuente principal: Maestro de Calles IDE Chile 2022, adaptado del índice de Azimut (solo comuna de Santiago). Barrios y territorios se tomarán de las capas oficiales cuando se publiquen en este repositorio.
Administración · incorporar capas oficiales

Opción excepcional de mantenimiento, no necesaria para cargar las direcciones. Las capas deben publicarse en /geocodificador/datos/ para estar disponibles a todos los usuarios.

3 · Procesar y descargar

Para convertir GeoJSON a GeoPackage en QGIS: clic derecho en capa → Exportar → Guardar objetos como → GeoPackage. La exportación GPKG directa requiere el backend GIS.
